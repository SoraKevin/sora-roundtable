# Prompt Examples

## Hybrid 默认模式

```text
蒸馏DNA：帮我蒸馏 Geoffrey Hinton 的 Academic DNA，输出一个可安装 Skill。默认用 Hybrid：先提取核心 Research DNA，再保留思想演化、张力和开放问题。
```

## DNA Kernel 模式

```text
进入Distiller模式，用 DNA Kernel 模式蒸馏 Karpathy 的研究判断系统。我主要想用它评审论文 idea、abstract 和实验设计，所以请高聚焦、高可操作，不要写成思想史。
```

## Open Framework 模式

```text
进入蒸馏模式，用 Open Framework 模式梳理 Judea Pearl 的研究思想谱系。重点保留因果推断、反事实、统计学争议、与机器学习分歧之间的演化和张力，不要压缩成几条口号。
```

## Application Mode

```text
用 Hinton Academic DNA 看一下我这个论文 idea：...
请输出 active lens、主要风险、需要补的证据、可能的实验设计。
```
