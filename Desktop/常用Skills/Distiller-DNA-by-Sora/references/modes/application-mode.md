# Application Mode — Use an Existing Academic DNA Lens

Use Application Mode when the user already has a target author/lens and wants to apply it to a concrete artifact.

## Supported Inputs

- paper idea;
- abstract;
- introduction;
- related work;
- method section;
- experiment plan;
- rebuttal draft;
- literature review;
- code/reproduction plan.

## Workflow

### Step 1: Classify artifact

Identify whether the task is ideation, writing, method critique, review, rebuttal, or learning.

### Step 2: Select active lenses

Choose 1–3 Research DNA Primitives relevant to the artifact.

### Step 3: Apply with evidence discipline

- If current facts or citations matter, search/read sources first.
- If only structure/method critique is needed, apply the lens directly.
- Do not invent citations or author opinions.

### Step 4: Output format

Use this compact answer shape:

```markdown
## Verdict
...

## Active Lens
- Lens: ...
- Why active: ...

## Diagnosis
1. ...
2. ...
3. ...

## Concrete Revision / Experiment / Review Actions
- ...

## Boundary
- source-backed / inferred / uncertain notes
```

## Safety

Do not rewrite prose to imitate the author. Transform structure, argument, evidence, and claim calibration instead.
