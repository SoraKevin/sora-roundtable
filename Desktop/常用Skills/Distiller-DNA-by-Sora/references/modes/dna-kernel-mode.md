# DNA Kernel Mode — Focused Research DNA Extraction

Use DNA Kernel Mode when the user wants the author's sharpest, most actionable essence.

## Trigger Signals

- “提取精华”
- “压成最核心DNA”
- “像他/她一样判断”
- “帮我用这个作者评审”
- “我只要最锋利的研究品味”

## Goal

Create a compact, high-signal research operating system.

## Required Outputs

### 1. Research DNA Primitives

Extract 5–9 primitives. Each primitive must pass:

- recurrence across papers/talks/code;
- transfer power to new problems;
- distinctiveness versus neighboring authors/schools;
- concrete operational use;
- clear failure mode.

### 2. Method DNA

5–10 rules of the form:

- If evidence is weak, this author would first ...
- If the method is overcomplicated, this author would ...
- If the benchmark is misleading, this author would ...

### 3. Evidence Standard

3–5 concrete standards:

- what counts as convincing;
- what baseline matters;
- what ablation/proof/study is missing;
- when a claim is overreaching.

### 4. Review DNA

A usable checklist for reviewing an abstract, method, experiment, or rebuttal.

### 5. Anti-patterns

What this author/lens would likely reject.

## Compression Rules

- Prefer fewer, stronger primitives.
- Remove generic advice.
- Keep evidence IDs attached.
- Never imitate prose; extract structure.
- When in doubt, downgrade weak claims to inferred notes or boundaries.

## Quality Gate

The result must be able to answer:

> Given a new paper idea, what would this research lens immediately question, improve, or reject?

If it cannot answer that concretely, the Kernel is not ready.
