# Hybrid Mode — Default Academic Author Distillation

Hybrid Mode is the default mode of Distiller-DNA-by-Sora.

## Goal

Preserve both:

1. **DNA Kernel sharpness**: the author should feel recognizably different from generic good scholarship.
2. **Open Framework breadth**: the author must not be flattened into slogans, catchphrases, or fixed positions.

## Workflow

### Step 1: Kernel First

Extract 5–9 Research DNA Primitives.

Each primitive must include:

- Definition
- Source evidence
- Transfer use
- Distinctiveness
- Failure mode
- Confidence

Promote a primitive only if it is recurring, transferable, distinctive, and actionable.

### Step 2: Framework Expansion

After the kernel is stable, expand into:

- Research Field Map
- Evolution Timeline
- Tension Ledger
- Open Problems
- Alternative Readings
- Do-not-overfit Rules

### Step 3: Application Layer

Make the final Skill useful for:

- research ideation;
- abstract / intro / related work restructuring;
- method design;
- review checklist;
- rebuttal strategy;
- literature positioning.

## Output Shape

The target Skill should contain both sections:

1. **DNA Kernel**: primitives, method DNA, evidence standard, review DNA, anti-patterns.
2. **Open Framework**: field map, evolution, tensions, open problems, alternative readings, honest boundaries.

## Failure Modes

- Too sharp: becomes sloganized and overconfident.
- Too open: becomes a generic literature survey.
- Too stylistic: imitates prose instead of extracting research structure.
- Too reverential: ignores criticism, failed replications, or field disagreements.
