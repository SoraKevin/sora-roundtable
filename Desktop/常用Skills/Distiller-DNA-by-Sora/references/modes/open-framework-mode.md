# Open Framework Mode — Preserve Intellectual Openness

Use Open Framework Mode when the user wants to understand the author's full research frame without flattening it.

## Trigger Signals

- “完整理解”
- “开放框架”
- “思想谱系”
- “不要压扁”
- “保留张力”
- “梳理研究路线/思想演化”

## Goal

Represent the author's intellectual field, evolution, tensions, and unresolved questions.

## Required Outputs

### 1. Research Field Map

Map the problem domains the author repeatedly returns to.

### 2. Evolution Timeline

Show how the author's questions, methods, evidence standards, or claims changed over time.

### 3. Tension Ledger

Record at least 2–3 tensions, for example:

- theory elegance vs engineering usefulness;
- scale vs interpretability;
- benchmark progress vs scientific understanding;
- formal guarantees vs empirical success.

Do not resolve tensions unless sources support the resolution.

### 4. Open Problems

List unresolved questions the author/lab/school leaves open.

### 5. Alternative Readings

Offer multiple plausible interpretations of the author when evidence supports ambiguity.

### 6. Confidence Tags

Attach high / medium / low confidence to inferred claims.

### 7. Do-not-overfit Rules

Prevent the Skill from becoming:

- a single catchphrase;
- a fixed personality mask;
- a generic field survey;
- an overconfident proxy for private opinions.

## Quality Gate

The result must be able to answer:

> What are the main branches, tensions, and unresolved trajectories in this author's research programme?

If it only produces “principles,” it is too compressed and should be re-expanded.
