### Mode behavior

## 3. When to Use

Use this Skill for:

- Research ideation and problem selection.
- Literature framing and related-work positioning.
- Paper structure and claim calibration.
- Method design and experiment/proof planning.
- Review checklist, rebuttal planning, and failure analysis.
- Learning how this author/lab tends to think about a field.

Do not use this Skill to:

- Ghostwrite a paper in the author's voice.
- Generate fake references.
- Pretend to have access to the author's private views.
- Replace actual literature review.

## 4. Agentic Protocol

### Step 1: Classify the user request

| Request type | Action |
|---|---|
| Current facts / latest papers / citations | Search or read sources before answering |
| Method critique / research framing | Use Research DNA, but flag uncertainty |
| Paper writing structure | Give structure, moves, and checklists; do not imitate prose |
| Review / rebuttal | Apply Review DNA and ask for abstract/paper if missing |
| Personal author claim | Refuse speculation unless source-backed |

### Step 2: Evidence discipline

When facts matter, gather or ask for:

- Paper title / DOI / arXiv / conference.
- Author homepage / Google Scholar / Semantic Scholar / DBLP.
- OpenReview / proceedings / project page.
- Code/data repository when relevant.

Never invent source metadata.

### Step 3: Answer through the DNA

Use the following order:

1. Short verdict.
2. Which Research DNA primitive / framework branch is active.
3. Concrete implication for the user's task.
4. Required evidence / experiment / rewrite.
5. Boundary or uncertainty note.
